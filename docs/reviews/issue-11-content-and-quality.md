# Issue 11: Content and Structural Qualification

2026-10-13. Source: `4b154a6`, `aa8395b`, `bd55330`, `00ff80b` on
`codex/agentic-game-a1`. **PARTIAL issue delivery.** This qualifies canonical

## Implemented

- Shared contract templates, quest progression/payment, collectible eligibility,
  chest eligibility and loot rules. Existing actual-game callers use the same
  extracted functions; canonical callers do not manufacture a partial GameState.
- Four-room structural qualification batches. Reverse generation ordinals reduce
  the ordered reciprocal tree into addressable O(rooms) scratch, using the same D1
  room count, reachability, edge count, fork count and longest-chain criteria.
  The 100,003-room fixture checks bounded prefix work, NOT a complete huge floor.
- Copy-on-write primary namespace witnesses bind every topology source and scratch
  reduction. Changed/deleted/re-versioned data invalidates the proof without a
  full-floor scan. Unrelated roster/content/other-floor writes preserve it.
  Missing controls cannot restart over surviving prior scratch.
- Two-room content batches require completed structural qualification and roles.
  The pinned new module content policy places one cache in each treasure room,
  creates guild offers from shared templates and persists explicit room membership.
  No inventory, acceptance, reward or knowledge is generated by preparation.
- Independently addressed chests, contracts and accepted quests. Explicit
  accept/open/claim commands commit roster changes, award provenance, objective
  progress, reward gold, checkpoint and receipt atomically. Room visits only
  advance an already accepted local scout/locate task. Nothing accepts or loots
  merely because navigation crosses a chest.
- Quest award history remains separate from present ownership. Pack/stash moves
  do not erase it; claims verify the exact opened source chest and collectible.
  An already-opened cache cannot issue a new unfulfillable fetch offer.
- Bounded floor/status contract and quest pages, with historical snapshot reads.
  These remain authoritative internal queries, not actor disclosure tools.
- Transaction-local immutable record/node caching. A valid large pack previously
  exhausted the read allowance by repeatedly fetching shared radix branches.
  Cache lifetime and retained bytes are bounded by one transaction; new
  transactions see new roots, and reads do not republish records.

## Review Repairs

Independent review found and reproduced:

1. A foreign room-to-contract reference could complete an unvisited room's scout
   quest. Reciprocal floor/room/contract identity is now checked before progress.
2. A missing or changed award source could still produce gold. Completion now
   requires award provenance and claim reads verify that original source.
3. A replaced non-cursor scratch reduction could falsely qualify a failing chain.
   The whole scratch primary namespace is now pinned, not only the last node.
4. Deleting a processed remote connection/passage did not invalidate qualification.
   All topology primary namespaces are now pinned and rechecked.
5. Deleting both quality controls could restart established failed scratch. Begin
   now rejects that state rather than creating fresh controls.

Parent native regressions cover the content findings. Independent rerun of all
three topology repros plus their control passed; that reviewer also reported
99 focused quality/provenance/witness checks passing. This is not a claim of
cryptographic protection against arbitrary raw database-byte tampering.
